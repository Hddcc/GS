# Third-Party Notice: IAFM IDM+ARM Adaptation

This experiment is an independent clean-room implementation from the equations
and diagrams in the CVPR 2026 IAFMNet paper and supplementary material. No
third-party IAFMNet source code is copied or redistributed. No official code
repository was found at the time of implementation.

The experiment implements only an adapted soft IDM-guided ARM path. It does not
claim to reproduce the full IAFMNet, its sparse IGRA path, or its published
benchmark numbers.
